# TDO 负阻 LC 传感振荡器仿真
Twaltz低功耗振荡器思想的LTspice仿真文件。
该部分探索能否将连续变化的传感电容直接加入振荡网络，使其同时完成：

```text
模拟量（温度、呼吸等信息）
      ↓
电容变化
      ↓
LC振荡频率变化
      ↓
高频调制信号
```
从而避免前一呼吸实验中RC充放电振荡器较高的功耗。

## 1. 文件

```text
circuit/
├── README.md
└── tdo_sensor_oscillator.asc
```

`tdo_sensor_oscillator.asc` 即为完整 LTspice schematic

## 2. 仿真环境

使用LTspice打开：
```text
tdo_sensor_oscillator.asc
```
即可运行仿真。

本仿真的目的主要是验证“负阻自激振荡 + 连续变化传感电容”这一机制是否可行，TDO并未采用具体器件模型，而是使用工作点附近的三阶非线性负阻模型描述其等效特性。并不能用于精确预测真实隧道二极管器件的功耗或高频性能。

## 3. 负阻模型

TDO 工作点设置为：
```text
Vb = 120 mV
```
Behavioral Current Source `B1` 使用：
```text
I=-{G0}*(V(td)-{Vb})+{K}*(V(td)-{Vb})**3
```
描述负阻区域附近的非线性 I-V 特性。

主要参数为：
```text
Vb = 120m
G0 = 1.5m
K  = 0.1

Lb = 10u
Cb = 1n
Rb = 100
```
其中 `Lb / Cb / Rb` 构成偏置和阻尼网络。

## 4. LC 谐振网络

主要谐振参数为：
```text
L    = 50.7 nH
Csen = 200 pF
Rloss = 1 kΩ
```
其中：

* `L`：谐振电感；
* `Csen`：传感电容的中心值；
* `Rloss`：用于表示谐振网络等效损耗。

## 5. 时变传感电容

实验假设传感电容连续变化：

[
C_s=C_sen+ΔC*sin(2πft)
]

参数设置为：

```text
C_sen   = 200 pF
ΔC     = 20 pF
f = 20 kHz
```

因此：

```text
Cmin = 180 pF
Cmax = 220 pF
```
对应模拟感知量缓慢改变等效电容的过程。

## 6. 仿真设置

瞬态仿真设置为：
```text
.ic V(td)=120m V(osc)=1u
.tran 0 120u 0 0.2n uic
```

其中给 `V(osc)` 初始扰动，用于启动自激振荡。

运行仿真后观察：

```text
V(osc)
```

即可看到高频自激振荡波形。

## 7. 预期结果

仿真开始后，振荡幅度逐渐建立，并在约：
```text
12 μs
```
后进入较稳定状态。
当传感电容在：
```text
180 pF → 220 pF
```
之间连续变化时，振荡频率约为：
```text
53.8 MHz → 47.4 MHz
```
即电容增大时，LC 谐振频率下降。
因此可以观察到：
```text
连续电容变化
      ↓
连续振荡频率变化
```
说明利用传感电容直接控制高频振荡频率在该简化模型下是可行的。

## 8. 与前一呼吸感知标签的关系

前一部分呼吸 Backscatter 标签使用：

```text
传感电容 + 电阻 + 施密特反相器
```
形成 RC 充放电振荡器。

但实验中标签整机功耗达到约：
```text
3 mW
```

且较大的寄生电容会进一步增加动态充放电功耗，因此进一步考虑LC自激振荡的可行性

希望在保持“传感量 → 电容 → 频率”这一映射关系的同时降低振荡器本身的功耗。

当前模型没有使用真实 TDO 的完整 I-V 曲线，没有加入真实器件的结电容和寄生参数，没有模拟 PCB 布局与高频互连，没有完成实际PCB制作和硬件测量，仿真得到的 μW 功耗不能直接作为实际电路功耗预测。

为后续实现低功耗模拟量传感标签提供了一种可能的电路方向。
